## Processamento de Imagens - Morfologia Matemática
É um jeito de olhar uma imagem como se fosse um conjunto. 
- Dilatação: Se o ponto de inserção do elemento estruturante estiver pintado, entoa grava o elemento estruturante na imagem.

Elemento estruturante: Se escolhermos direito o elemento estruturante, podemos fazer algumas coisas. Podemos "engordar" uma imagme para a direita por exemplo.

O 'X' no (0,0) eh no caso do slide, mas ele pode estar em qualquer lugar. O 'X' eh uma origem. AA dilatação preenche todos os buracos menores da imagem. Uma imagem cheia de ruído, fica preenchida.

- Erosão: Faz o contrário da dilatação. Vou ancorar na imagem o elemento estruturante, que aceitam o padrão. Com isso não varremos toda a imagem. O que tiver pintado, no elemento estruturante será apagado, por exemplo.
Todas as transformações são bem difíceis de descrever sem visualizar. Só mudando o elemento estruturante, é possível fazer várias operações diferentes.

OpenCV tem metodos pra voce voce mandar como parametro a imagem e o elemento estruturante.

- Fechamento: Uma dilatação, seguida de uma erosão. Tira coisas do meio e deixa a aborda. Primeiro dilatação, depois erosão
- Abertura: Erosão primeiro depois dilatação. Faz o contrário do fechamento. Tira coisas da borda e deixa o miolo.
